## About

The core features are comparable to those provided by [Maimemo](https://www.maimemo.com), with the addition of the following functionalities:

* Mastery Decay: This feature is intended to track and enhance your familiarity with the vocabulary over time.

* Approximity Search: This tool enables you to swiftly add supplementary notes.

I trust that these features will significantly enhance your experience with the project.
